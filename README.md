🚀 Yeni projem yayında: ASP.NET Core 9 MVC ile dinamik Portfolyo Sitesi ve Admin Paneli

Udemy'de Murat Yücedağ hocamın portfolyo projesi eğitimini takip ederek kendi kişisel portfolyo sitemi geliştirdim. Sayfadaki tüm içerik veritabanından geliyor ve bir yönetim paneli üzerinden yönetilebiliyor.

🔹 Sitede neler var?
• Hakkımda, Yetenekler ve Deneyimler bölümleri
• Portfolyo, Referanslar ve İletişim alanları
• Her bölüm ayrı bir ViewComponent olarak tasarlandı

🔹 Admin panelinde neler var?
• Gelen mesajlar kutusu (okundu / okunmadı olarak işaretleme, silme, detay görüntüleme)
• Deneyimler için ekleme, güncelleme ve silme (CRUD) işlemleri
• Yapılacaklar listesi (To-Do)
• Yetenek ve mesaj sayılarını gösteren istatistik sayfası

🛠 Kullanılan teknolojiler
• C# ve ASP.NET Core 9 MVC
• Entity Framework Core (Code First, Migrations)
• MS SQL Server
• ViewComponent yapısı
• HTML5, CSS3, Bootstrap, JavaScript / jQuery

Bu projede katmanlı düşünmeyi, Entity Framework ile veritabanı işlemlerini ve ViewComponent'lerle sayfayı parçalara bölmeyi pekiştirme fırsatı buldum. Emeği için Murat Yücedağ hocama teşekkür ederim. 🙏
